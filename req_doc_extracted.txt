背景
基于提升企微加群人数规模的目标，计划优化之家APP->加企微车系群的流程。
本次计划增加企微车系群列表页、配套车系群管理后台。

1、用户加群学习成本较高

本期解决

非本期解决
为什么要做车系群管理后台？
提升企微人数规模：车系论坛可直接投放车系群二维码，加群路径更短——后台管理是前置必要条件。
提升加群流程效率及体验：
H5车系群列表页需要按车系名称A-Z排序——保证浏览车系群列表的基础体验。
H5车系群列表页点击立即加群需要跳转到企微群url——企微后台不提供企微群url，依赖技术解析二维码。

H5车系群列表页
增加H5车系群列表页
概述：该页面用于投放到企微环境下打开，需要H5实现且免登录。
页面标题：车友群
是否登录：免登录可访问该页面。
列表规则

列表排序：按车系群名称A-Z排序。
列表分页：每页20条，上拉无限加载。页面上拉到底时显示“已经到底了”
列表空数据时，页面内提示“空空如也”。
列表操作：
实时过滤：

匹配结果中，命中的关键词高亮显示。（本期不做）
立即加群：点击列表item（cell），跳转到相应企微车系群页（活码）。
列表元素
车系图片：
车系图显隐逻辑：有则展示，无则展示默认图。
车系图数据来源：服务端下发，根据管理后台配置的车系ID获取该车系图。
车系群名称：单行展示，超出显示...
操作按钮：
按钮文案：立即加群
按钮链接：点击跳转到企微车系群页（活码）。

2、管理后台支持管理车系群
模块
配图
说明
车系群管理入口
增加【车系群管理】入口
后台地址：http://clubmanager.autohome.com.cn/manager/home
后台菜单：【车友会】-【车友会成员数据】下方，增加【车系群管理】
查看车系群列表
增加【车系群管理】列表页
概述：运营人员可在后台查看及管理所有企微车系群（活码）。
列表规则
列表数据源：从服务端获取全部有效车系群列表。
列表筛选：支持按【车系群名称】+【启用/禁用状态】联合过滤（车系群状态：全部、启用（默认）、禁用）
列表排序：默认按创建时间从新到旧排序。
列表分页：统一分页。
列表空数据时页面内提示“暂无数据”。
列表元素
车系ID
论坛ID（本期不加）
车系群名称：单行展示
车系群二维码：展示缩略图，支持点击查看大图。
车系群链接
操作
状态：启用/禁用，（默认为启用）（禁用后前端不外展）
编辑
添加/编辑车系群
添加车系群
编辑车系群
支持添加/编辑车系群
服务端逻辑：
服务端添加/编辑时，提交时判断：
每个车系ID只能关联1个车系群（活码），一对一的关系。
每个车系群的活码（即车系群url），不能重复。
添加车系群（批量）
第1步：批量上传二维码（JPG/PNG格式）。
上传数量限制：用户可多次上传二维码，但整个表单最多支持10条数据。前端过滤超出数据并message全局提示“单次上传已达10条”
上传内容限制：前端校验图片是否二维码，若非二维码则过滤该条数据。
第2步：根据上传二维码，展示车系群列表。
列表数据源：展示用户上传的二维码列表。
列表排序：按二维码选择的顺序依次展示。
列表数量：单次最大支持10条数据。
列表交互：
上传前：展示“暂无数据”。
上传中：展示loading。
上传后：展示toast“上传完成”。
列表字段：
车系群名称：必填，获取及展示用户上传的二维码文件名。（编辑时允许修改）
车系ID：必填。（编辑时允许修改）
论坛ID：本期不加
车系群二维码：必填，获取及展示用户上传的二维码。（编辑表单中，置灰不支持修改此项）
车系群url：必填，根据上传的车系群二维码自动解析出URL。（编辑表单中，置灰不支持修改此项）
表单操作：
取消：关闭弹窗。
保存：
保存时校验必填项：车系群二维码、车系群名称、车系ID、车系群URL。
保存成功时关闭弹窗，并刷新车系群列表。

1、问题记录
问题
备注
1. 单个车系 ID 只能绑定 1 个车系群，新增 / 编辑重复车系 ID   如何拦截：前端校验还是后端唯一索引？ 
单个车系ID只能绑定1个车系群，后端校验提交失败给与提示
2.   实时过滤只处理本地已加载数据，还是服务端重新请求？影响分页、无限加载，需确认是否会漏过滤。 
实时查所有有效车系群，前端最多展示20条实时过滤结果
3.   二维码 URL、车系 ID 解析失败如何处理：弹窗报错还是字段留空？ 
字段留空，比如上传10个码，1个没解析出来，该字段留空需要人工填或删
4.   后台列表车系群链接能否编辑？和 “车系群 URL” 是否为同一个字段？ 
是同一个字段，不支持编辑
5.   中文 A-Z 排序规则确认：拼音首字母 / 全拼排序？中英文混排顺序？ 
先按品牌名称 A-Z
6.   拼音模糊匹配范围（全拼 / 首字母 / 大小写 / 多音字），搜索高亮由前端还是服务端实现？
无高亮逻辑，点「搜索」按钮，由接口返回搜索结果
7.   批量上传图片限制（大小、分辨率），非二维码、格式错误对应的提示文案确认
可忽略该问题，批量上传只展示解析成功的，解析失败的字段留空即可。
目前二维码都是从企微后台下载，一般是396*396，png
8.   搜索无结果、车系名带特殊字符时的页面展示效果
搜索无结果展示“暂无数据”即可。车系名特殊字符正常展示即可。
9.   H5 免登录暴露全部车系群，是否需要增加访问频控控制？
不需要
10.   需求里的论坛 ID 代表什么，业务作用是什么？ 
暂无实际应用场景，预留字段，未来可能会投放到论坛列表页（实例：论坛存在多个车系群，则取1个最新的）
11.   二维码重复上传了具体展示规则 
添加/编辑时，校验二维码（url）不能重复，否则保存失败
