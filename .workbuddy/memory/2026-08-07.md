## BUG 修复：游戏「找规律」点击后页面卡死（无限循环）
- 根因：`patternGame` 里 `while (opts.size < 4)` 用随机从「非答案项」池里取干扰项。当题目的非答案项全部相同（如 `🔴⭐🔴⭐🔴` 只有 🔴）或整题去重后不足 4 个符号（如三色轮流）时，选项集永远凑不到 4 个不重复值，死循环阻塞主线程 → 页面卡死。
- 修复（`modules.js` patternGame）：先 `Array.from(new Set(...))` 取题目内非答案去重池，再从 emojiPool 补去重候选，合成 `src`；`target = Math.min(4, 1 + src.length)`；**洗牌 src 后顺序取**填满选项（不依赖随机命中，任何随机分布都必然终止）。
- 验证：jsdom 压力测试遍历全部 12 个 PATTERNS + 3 种常量随机，均不再卡死，每个选项均稳定出 4 个瓷砖；重建 standalone（927KB）并部署同一沙箱 HTTP 200。
- 旁查：`shapesGame` 同样写法但 SHAPES 有 10 个去重项，不会触发，未改。

## BUG 修复 + 增强：认识时间模块（秒针走动 / 表盘数字 / 选项出框）
- 用户反馈：① 需要秒针走动效果 ② 表盘要有对应数字 ③ 猜一猜三个选项文字出框。
- 根因：原 `clockFaceSVG(h,m)` 只画时分两针 + 刻度，无数字、无秒针；实时钟用 `setInterval(tick,1000)` 仅每秒整秒重绘、无连续走动视觉。`.tile` 固定 64px 宽 + 30px 字号，"12:00" 五字符超宽溢出。
- 修复（`modules.js`）：
  - `clockFaceSVG` 改写为 `clockSVGShell()`（返回带 `#hrHand/#minHand/#secHand` 三针 + 12 个数字 text 的 SVG 外壳）与 `setClock(svg,h,m,s)`（按角度 setAttribute 旋转三针）。
  - 实时钟改为渲染外壳一次 + `requestAnimationFrame` 连续帧（秒针用 `s + ms/1000` 平滑扫动，明显走动）；`timeclock._raf` 记录句柄，离场（`!liveClock.isConnected`）时 `cancelAnimationFrame` 停止；无 rAF 环境降级 `setTimeout` 兜底。文字加"秒"（X点X分X秒）。
  - 猜一猜钟面用同样外壳、`setClock(...,0)` 静态显示；选项 `t.className = "tile time-opt"`。
- CSS：`.tile.time-opt { width:auto; min-width:78px; height:56px; padding:0 12px; font-size:22px; white-space:nowrap; }`；`.tile-row` 加 `justify-content:center` 让选项居中不溢出。
- 验证：`node --check` 通过；jsdom 冒烟测试（_test_timeclock.js）全 PASS——live/guess 均含 secHand、表盘 12 数字、3 个 time-opt 瓷砖、秒针 transform 在 120ms 内变化（确认走动）。重建 standalone（约 929KB，0 外部引用）；部署同一 CloudStudio 沙箱 ff27e10f，HTTP 200，标记 secHand/time-opt/clockSVGShell 齐全。
