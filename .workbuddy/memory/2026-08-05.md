## 修复：公网打不开（白屏 + 按钮无反应）
- 现象：用户打开公网链接后，页面只有顶部一个大白按钮，点击无反应。
- 根因（非代码 bug）：CloudStudio 公网静态托管对**子目录资源（assets/*.js、*.css）返回 0 字节**（HTTP 200 但 body 为空）。
  - CSS 0 字节 → 无样式，顶部栏变白块，按钮显示为默认大白按钮；
  - JS 0 字节 → 脚本未加载，所有点击无反应。
- 修复方案：把整个应用打包为**单一自包含 `standalone.html`**，将 CSS、拼音引擎(pinyin-pro.mjs)、395首诗词数据、全部 JS 内联进一个文件；CSP 改为 `script-src 'unsafe-inline'`（单文件无外链，安全可控）；`genPinyinLine` 已有 pinyinPro 缺失兜底，诗词模块不会卡死。
- 构建脚本：`build_standalone.py`（正则内联 + `</script` 转义 + 替换 pinyin 引擎末尾 export 为 `window.pinyinPro = pinyin`）。
- 验证：`node --check` 各 JS 通过；jsdom 加载 standalone.html，12/12 模块渲染正常、零运行期错误；公网根路径与 /standalone.html 均 HTTP 200 且 0 个外部 assets 引用。
- 教训：**CloudStudio 这类公网静态托管对子目录资源的可靠性不可控，前端项目优先用单文件内联（standalone.html）部署**，避免依赖多文件子资源。

## 修复：整页被遮罩蒙层+中心白圆挡住、点不动（真因）
- 现象：用户反馈不仅是设置弹窗，整个页面有一层遮罩蒙层，正中间一个白色圆形区域，整页点击无反应（本地与沙箱都这样）。
- 真因（CSS 规范陷阱，非逻辑 bug）：`index.html` 的三个弹窗用 `hidden` **属性**隐藏，但 `style.css` 里 `.modal-mask { display:grid }` 是**作者样式**，会盖过浏览器 UA 默认的 `[hidden] { display:none }`，导致三个遮罩（userModal/settingsModal/toastModal）与移动端 `scrim` 在加载时**全部显示**。最上层空的 `toastCard` 即"中心白圆"，半透明蒙层挡住整页点击。
  - 为何 jsdom/之前没发现：jsdom 不做 CSS 布局；且此前多文件部署时 CSS 是 0 字节（无样式反而没触发显示）。
- 修复：在 `style.css` 增加 `[hidden] { display: none !important; }`（与既有 `.hidden` 类并列）。`!important` 盖过 `.modal-mask{display:grid}`；JS 用 `el.hidden=false` 移除属性后弹窗正常显示。本地 `index.html`（<link> 同一份 css）与沙箱 `standalone.html`（内联同一份）均修复。
- 验证：重新生成 standalone.html（822278B），grep 确认 `[hidden]` 规则已内联、3 个 modal-mask 带 hidden 属性、0 外部引用；jsdom 12/12 模块零错误；公网根路径与 /standalone.html HTTP 200。
- 教训：**任何用 `hidden` 属性控制显隐的元素，务必加 `[hidden]{display:none!important}`**，否则作者 `display` 规则会让它一直显示；且纯 jsdom 测试无法发现 CSS 布局类问题，部署后要用真实浏览器/爬取 HTML 核对。
