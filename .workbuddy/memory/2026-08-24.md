## 整站访问密码限制（新需求，已完成产物准备）
用户问「如何限制别人使用这个网址」。现状：GitHub Pages 完全公开、无密码功能，前端登录无法真限制。
- 决策：用户选「整站加访问密码(推荐)」——迁移到 Netlify/Cloudflare Pages 开启站点级密码（网络层真限制）。
- 已准备产物：`amy-learning-netlify.zip`（`_deploy` 43 文件/3.1MB，排除 standalone.html 与 generate_china_map.py）、`_deploy/netlify.toml`（缓存配置）、`部署与访问密码指南.md`（Drop 拖拽+开密码图文步骤）、`deploy_netlify.py`（可选 API 一键部署，需填 token/site_id）。
- 关键约束：**开启密码那一步必须在用户本机 Netlify 控制台点（免费），我无其账号无法代点**；旧 GitHub Pages 链接仍公开，需停止分享或关掉 Pages（仓库 Settings→Pages→Source=None）。
- 与短信登录关系：短信登录=应用层遮挡（已搁置），整站密码=网络层真限制（当前主线）。
