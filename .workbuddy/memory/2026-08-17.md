# 2026-08-17 工作日志

## 修复：跨模块实时同步 / 切换模块不刷新（用户反馈 bug）

**根因**：`notifyBankChange()`（modules.js）做了两件错事：
1. 把「当前正在查看」的模块缓存也 `delete` 了 → 之后 navigate 时 `moduleCache[current]` 已不存在，无法 `removeChild`，导致旧模块 DOM 残留在 content 里（堆叠/孤儿），表现就是“切换后不更新/状态错乱”。
2. 只硬编码失效 `["shizi","book","english","poetry","wordbank"]` 5 个模块，绘本已读/背诗/绘画/游戏/逻辑/计算等数据变化不会让 `performance`/`calendar` 等模块失效，切换过去看到旧数据。

**修复**：
- `assets/app.js`：新增 `S.onChange(invalidateStaleModules)`，在**任意** store 变更（加词/加字/背诗/读绘本/绘画/游戏/打卡…全部 emit）后，把所有「非当前」模块缓存 + 滚动位清空；当前模块保留（由各自 onAdded/render 原地刷新，避免打断阅读器/拼图）。彻底解决“切换其他模块不更新”。
- `assets/modules.js`：`notifyBankChange()` 改为空函数（缓存失效已统一在 app.js 处理），去掉误删当前缓存的 bug。
- `test_smoke.js` 第 16 项断言改为验证新机制（非当前模块缓存被清 + 当前模块保留）。

**验证**：`node --check` 全过；`test_smoke.js` SMOKE_PASS；新增 jsdom 端到端同步验证（点击导航真实切换）全部 PASS——加词后词库实时出现、读绘本/背诗后其它模块缓存失效、切换无堆叠/孤儿 DOM。
